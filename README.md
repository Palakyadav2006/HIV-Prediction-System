# HIV-Prediction-System
AI-based HIV Patient Health Prediction System using Machine Learning. Data from the World Health Organization is preprocessed and used to train a Random Forest model. Includes data visualization (scatter, bar, histogram, line, box plots) for analysis.

# HIV Patient Health Prediction System

##  Description
This project predicts HIV patient health status using Machine Learning.

##  Features
- Data preprocessing from WHO dataset
- Feature engineering
- Visualization using multiple graphs
- Random Forest model for prediction

## Technologies
- Python
- Pandas
- Matplotlib
- Scikit-learn

##  How to Run
1. Install libraries
2. Run main.py

##  Output
- Model accuracy
- Graph visualizations
